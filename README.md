# applied-llm-systems

Coursework for COSC-650 Applied LLM Systems at Maryville University during an 8 week Fall 2026 term. 

Addresses the core technical foundations of LLMs, including tokenization, transformer internals, scaling behavior, and pre-training objectives, followed by practical adaptation methods such as fine-tuning, LoRA, and instruction tuning. 

Work is organized into 8 topical subfolders and consists of Python Jupyter Notebooks written in Google Collaboratory and utilizing the Claude API.
